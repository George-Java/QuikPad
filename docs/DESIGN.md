# 视觉与交互设计 · Liquid Glass

## 1. 设计意图

Liquid Ink 的视觉语言来自「光穿过一层薄玻璃」：

- 背景不是纯色，而是缓慢漂移的柔焦液体色场；
- 内容层是半透明、带圆角的玻璃薄片；
- 边界有方向性的高光与底边折射；
- 层级依赖透明度、毛细边框和柔和阴影，而不是厚重的工具条；
- 动效只用于空间关系变化，不打断阅读。

写作优先级始终高于装饰：专注模式只留正文，工具入口都在可收起的底部玻璃坞里。

## 2. 颜色

### 浅色

| Token | 值 | 用途 |
| --- | --- | --- |
| background | `#F2F0EA` | 暖灰纸面 |
| onBackground | `#14201D` | 主文本 |
| primary | `#0B5D51` | 青绿墨色，链接/焦点 |
| secondary | `#3D6070` | 蓝灰，辅助信息 |
| tertiary | `#984A2E` | 陶土色，警示/当前查找 |
| surface | `#FBFAF7` | 玻璃底 |
| outlineVariant | `#C4CDC8` | 细分隔线 |

液体色场：薄荷 `#7FD9C4`、天蓝 `#8CB9FF`、蜜桃 `#FFB49E`、丁香 `#CDB8FF`、暖金 `#FFD58A`。

### 深色

| Token | 值 | 用途 |
| --- | --- | --- |
| background | `#07110F` | 深墨 |
| onBackground | `#EAF3EF` | 主文本 |
| primary | `#7CE2CC` | 薄荷荧光 |
| surface | `#0D1A17` | 玻璃底 |
| error | `#FFB4AB` | 删除/错误 |

深色下液体色场降低明度，只保留光的存在感，不让彩色干扰正文。

### 玻璃透明度

- 浅色：面板顶部 alpha 0.80，底部 0.52；
- 深色：顶部 0.62，底部 0.36；
- 增强对比模式：浅色 0.97/0.90，深色 0.94/0.86，边框更接近实体色。

正文颜色始终是 `onSurface`/`onBackground`，不使用闪烁或纯动画变色。正文行高 28sp，适合中文密集阅读。

## 3. 玻璃合成

实现位于 `ui/components/LiquidGlass.kt`。

### 3.1 背景

`LiquidBackground` 使用 5 个径向渐变光斑 + 一层斜向反射带：

- 渐变中心缓慢漂移，周期 52 秒；
- 径向渐变本身提供柔焦过渡，等价于低成本 pre-blur；
- 不使用逐帧截图/`RenderEffect` 背景采样，因为那会在中低端机上引发整屏重绘；
- 背景 Canvas 没有语义，不进入 TalkBack。

### 3.2 面板层次

每一层 `GlassSurface` 从后向前：

1. 半透明 surface 垂直渐变；
2. 可选的 tint（主色/危险色/选中态）；
3. 左上角 radial 折射高光；
4. 顶部 1px 方向性 specular 高光；
5. 1px 渐变描边（上亮下暗）；
6. 圆角裁剪。

阴影由 Material `Modifier.shadow` 与主题色混合；省电模式直接关闭增强阴影。没有对每个块叠加玻璃，避免滚动时大量离屏层。

### 3.3 圆角尺度

| 层级 | 半径 |
| --- | --- |
| 文档面板/大卡片 | 24–30dp |
| 页面顶部玻璃条 | 24dp |
| 底部 Dock | 26dp |
| 图标按钮 | 16dp |
| 语法 Chip | 14dp |
| 小型信息胶囊 | 10–12dp |

## 4. 布局

### 4.1 Home

垂直节奏：

1. 品牌行（48dp logo + wordmark + 设置入口）；
2. 情绪化大标题 + 一句价值说明；
3. 新建 / 打开两个玻璃主操作；
4. 最近文档；
5. 本地隐私说明；
6. 页脚。

最大内容宽度 760dp，手机窄屏两侧 20dp；超出滚动。Hero 使用 `displayMedium`，在放大字体时自然换行。

### 4.2 Editor

```
safe drawing area
┌────────────────────────────────────────┐
│ glass top bar: back · title/status · 目录 · save · ⋯ │
├────────────────────────────────────────┤
│                                        │
│            mode content                │
│   source / split / rendered preview    │
│                                        │
├────────────────────────────────────────┤
│ optional find/replace glass panel      │
│ optional format glass panel             │
│ bottom glass dock                      │
│  [ 源码 | 实时 | 预览 ]                 │
│  字数/时长        undo redo find Aa 专注 │
│  预览时额外提供「阅读外观」入口            │
└────────────────────────────────────────┘
```

- 预览/源码都放在大圆角玻璃面板中。
- **实时**模式在竖屏上下分栏（38% / 62%），在可用宽度明显大于高度时自动切成左右分栏（44% / 56%）。
- 顶栏和底坞在专注模式下 `AnimatedVisibility` 收起，只留右下角的 48dp 退出圆片。
- 输入法出现时由 `WindowInsets.safeDrawing` 将整个工作区抬升，Dock 在键盘之上。
- 查找与格式面板互斥，避免三重工具条吞掉屏幕。

### 4.3 设置页

设置**不是叠加在主界面上的模态底部面板**。打开设置时，根组合树只渲染 `SettingsScreen`，Home 或 Editor 会离开组合树，因此不存在主界面文字从玻璃下方透出的可能。

设置页由两块独立玻璃组成：

1. 顶部玻璃胶囊：返回 / 标题 / 完成；
2. 占满剩余高度的设置卡片：可滚动，承载所有设置项。

设置卡片先呈现「阅读外观」分组：默认/羊皮纸背景、背景预读、液态玻璃开关、低/中/高强度分段控件、实时玻璃样张，以及界面动效开关。之后才是全局主题、自动保存、性能、对比度等设置。

设置卡片在普通主题下也强制使用最低不透明度：

- panel top `>= 0.97`
- panel bottom `>= 0.93`
- border `>= 0.72`

再叠加 14% 的 surface tint。这样既保留玻璃高光、折射边缘与圆角层次，也能保证正文、说明文字和分组标题在任何液体光场之上保持稳定对比。该规则由 `readableSettingsGlass()` 提供，并配有单元测试，防止以后为了“更通透”而把设置文字透明度降回去。

关闭设置时，`SaveableStateHolder` 会恢复此前 Home/Editor 的 `rememberSaveable` 状态（例如编辑器当前模式、查找词），但不会让主界面在设置期间参与渲染。

玻璃强度样张通过内层 `CompositionLocalProvider(LocalLiquidGlass provides baseGlass)` 使用**真实**玻璃 token，而不是设置页为了可读性提升过的 alpha，因此低/中/高强度和“玻璃关闭”的差异可即时看出来。

### 4.4 预览排版

- H1 31sp / 700，顶部有 34×3dp 主色渐变短线；
- H2 27sp，H3 22sp，H4–H6 逐渐接近正文；
- 正文 16.5sp / 28sp；
- 列表缩进每级 18dp；任务框 21dp 视觉、48dp 触控；
- 引用：3dp 渐变左栏（drawBehind 绘制，不用 IntrinsicSize 测量）+ 轻微玻璃底；
- 代码：深绿代码面 + 语言/复制 header + 横向滚动；
- 表格：148dp 固定列宽、横向滚动、表头加强；异常宽表最多渲染 32 列；
- 图片：最大 420dp 高，失败显示地址与 alt；
- 脚注：文末脚注区 + 点击弹出玻璃 Dialog；
- 超长列表每 48 项拆为一个 Lazy 项，保持目录 block index 映射；
- 羊皮纸：暖色纸面 `#F8EEDB → #EDDFC4`、深棕正文、低蓝光，独立于全局深浅色；正文对比度达到 WCAG AAA。

### 4.5 目录抽屉

- 入口在顶栏，图标带「目录大纲」语义；只在编辑器目的地出现。
- 右侧宽度为屏幕 86%，上限 360dp，外层有 24% 黑色遮罩；面板内部沿用设置页的可读玻璃下限。
- 目录标题行显示条目数量，关闭按钮 48dp；条目按 H1/H2/H3 缩进，支持两行省略。
- 面板本身是一个 LazyColumn；即使文档有数百个标题，也不会一次性组合全部行。
- 点击条目后：如果当前是源码模式，先切到预览；随后产生一次性定位请求，关闭目录并滚动到标题所在块。
- 无标题时显示空态；解析中显示“正在解析标题…”。

### 4.6 阅读页背景

- 默认：沿用应用 Material 3 主题的玻璃阅读面。
- 羊皮纸：固定暖色纸面，不读取应用深/浅色；正文、次要文字和链接分别使用固定的深色 token，保证深色应用主题下仍有清晰对比。
- 纸面使用细边框和轻微阴影；玻璃关闭时阴影移除，纸面仍保持哑光，不呈现液态高光。
- 设置页的阅读背景预览与真实阅读页使用同一组 token，避免“设置里好看、阅读页不匹配”。

## 5. 动效

| 场景 | 动效 |
| --- | --- |
| Home ↔ Editor | 240ms 淡入 + 0.985→1 缩放；退出 160ms；动效关闭时 0ms |
| 图标/主按钮按压 | spring 缩放 0.94–0.975 |
| 模式切换 | 260ms 背景与文字颜色渐变 |
| 查找/格式面板 | fade + expand/shrink vertically |
| 目录抽屉 | 150ms 淡入 + 0.97→1 缩放；关闭 120ms |
| 设置项展开/收起 | fade + expand/shrink |
| 液体背景 | 52 秒线性漂移；玻璃关闭或动效关闭时冻结 |
| 提示 Snackbar | 由 Material SnackbarHost 管理生命周期 + liveRegion |

以下任一条件成立时，所有过渡与背景漂移变为即时状态：

- 用户在设置中关闭「界面动效」；
- 系统动画时长比例为 0（“减少动态效果 / 移除动画”）；
- `PerformanceMode.REDUCED`；
- 自动性能模式判定为低内存设备。

视觉层次始终有静态替代（颜色、边框、字重），不仅依赖动画。

## 6. 可访问性

- 最小视觉触控面 48dp；图标按钮语义中有 `Role.Button`。
- 顶栏文档名一行省略，状态文本有颜色 + 文字双编码（不仅靠颜色）。
- 标题有 `heading()`；任务复选框是 `Role.Checkbox` + 选中状态。
- 行内链接通过 `CustomAccessibilityAction` 暴露操作，不能只为读屏提供视觉下划线。
- 系统字体缩放：关键容器使用 `heightIn` 而非绝对高度，文字使用 sp。
- 高对比模式：更高 alpha、实体感边框，不牺牲层级。
- 目录条目带层级与跳转语义；遮罩不进入读屏焦点；关闭按钮与条目均为 48dp 触控面。
- 羊皮纸正文/次要文字/链接分别通过 WCAG AAA/AA 对比度测试。
- 对错误 Snackbar 使用 `LiveRegionMode.Polite`。
- 输入框有可见 placeholder 和语义描述；源码区在大文件模式明确读作“大文件模式”。
- 跳过纯装饰 Canvas。

### 手动验收清单

1. 200% 字体缩放下，顶部栏、模式切换、设置面板、查找栏不截断关键按钮。
2. TalkBack 能读出文档标题、保存状态、每个图标按钮、任务状态和链接操作。
3. 键盘弹出时，光标所在行仍可见，底部 Dock 不遮住输入。
4. 横屏 + 分屏：实时模式可切换左右布局；无横向溢出崩溃。
5. 省电模式：背景静止、阴影消失，正文可读性不下降。
6. 系统深色/浅色切换时状态栏图标与背景对比正确。
7. 1 MB 文档中滚动、打开图片错误态、展开代码块不出现主线程 ANR 警告。
8. 打开含 H1–H3、表格、引用、>500 行的文档，连续滚动到文末再回滑，无白屏/闪退。
9. 点击顶部「目录大纲」，选择靠后的标题，目标标题落在可视区域内；关闭动效后变为即时定位。
10. 设置中切换默认/羊皮纸、玻璃开关/强度、动效开关；杀进程重开后设置保留，深色模式下羊皮纸仍为暖色。
11. 系统开启“移除动画”时，页面切换、目录、查找面板和分段控件不再播放过渡。

## 7. 性能降级规则

`PerformanceMode`：

- **AUTO**：`ActivityManager.isLowRamDevice == true` 或 API < 29 → 降低效果；
- **FULL**：玻璃高光、阴影、背景漂移全开；
- **REDUCED**：关闭背景动画与增强阴影，面板仍保持半透明与圆角。

玻璃开关/强度：

- 关闭玻璃：所有 `GlassSurface` 走不透明平面路径，背景不再漂移；阅读纸面仍可选。
- 低强度：面板更不透明，移除高光与增强阴影。
- 高强度：更通透，保留高光/阴影；在低端设备仍受 AUTO/REDUCED 约束。

超过阈值自动关闭：

- 源码 > 140k 字符：关闭源码语法着色/搜索结果背景着色；
- 代码块 > 48k 字符：跳过 token 化；
- 文档 > 1 MB：默认预览，并显示“大文件”状态；解析 debounce 拉长；
- 单个列表 > 48 项：拆成多个 Lazy 项；
- 表格 > 32 列：限制渲染列数；
- 图片解码尺寸：上限 2048×2048；
- 搜索结果 > 2,000：`2000+` 并只保留前 2,000 个高亮区间。

## 8. 关于真实 blur

Android 26+ 的 Compose 没有一个跨版本、无副作用的「读取背后图层并高斯模糊」API。强制用截图/离屏纹理实现会在滚动时产生显著开销，并打破低端机降级目标。

本项目采用：

- 背景光场本身以柔焦渐变呈现；
- 面板半透明叠色；
- 镜面高光、描边和轻微色偏模拟折射。

视觉上形成“透过玻璃看液体色场”的效果，但没有伪造无法兑现的实时底层模糊。后续可在 `GlassSurface` 后面接入 Haze 或 API 31 的 backdrop 实现，并把 `PerformanceMode.REDUCED` 固定为当前路径。
