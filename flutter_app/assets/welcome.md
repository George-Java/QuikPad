# 欢迎使用 QuikPad

> 一个不需要登录、打开即用的本地 Markdown 阅读与编辑 App。现在使用 Flutter 重建，滚动由 Flutter 的惰性列表负责，不再依赖旧的 Compose 预览渲染。

## 这次重构解决了什么

- 文档解析与渲染彻底分离；预览只接收不可变块列表。
- 每个标题、段落、列表项都是独立的惰性列表项。
- 超长列表不会再一次性测量全部行。
- 目录使用真实块索引定位，不靠像素估算。
- 阅读页默认是稳定的纸面/玻璃面板；模糊只用于固定顶栏和设置卡片。

## 阅读外观

在预览底栏打开「阅读外观」可以切换：

1. 默认阅读背景；
2. 羊皮纸暖色纸面；
3. 液态玻璃开关与低/中/高强度；
4. 界面动效开关。

所有设置都只保存在本机，重启后保留。

## Markdown 示例

### 行内语法

这是 **粗体**、*斜体*、~~删除线~~、`行内代码` 和一个 [链接](https://example.com)。

### 任务列表

- [x] 打开一个本地文件
- [ ] 滑到文末再回滑
- [ ] 打开目录跳到「长文测试」

### 代码块

```dart
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final prefs = await SharedPreferences.getInstance();
  runApp(QuikPadApp(settings: SettingsController(prefs)));
}
```

### 表格

| 能力 | 做法 |
| --- | --- |
| 目录 | H1–H3，真实块索引 |
| 滚动 | 惰性列表 + 精确 index 跳转 |
| 外观 | 默认 / 羊皮纸 |
| 数据 | 本地文件，无账号 |

### 引用

> 文档留在设备上，排版发生在本地。没有登录，没有云端初始化。
